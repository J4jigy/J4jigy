<product_requirements>
The application serves as a comprehensive financial management tool for petrol pump operations, accessible via a web interface (previously also mobile-focused). It must start in a completely empty state, allowing users to dynamically add and manage all data. Key features include:
- **Fuel Dispenser Management**: Users can add unlimited custom product types, record sales, and manage credit sales (party name, vehicle number, product, LTR, amount), DT Plus/Fleet Card entries (party name, LTR, amount), Expenses (name, amount), and Lubes (name, LTR/ml, rate, amount) with detailed fields. All these sections must support adding multiple entries via Plus icons and individual deletion.
- **Cash Management**: A dedicated Cash section on the home page (business tab, now to be moved to finance tab) for tracking cash flow, featuring search, sorting, and pagination. It must also start empty.
- **Persistence**: All user-added data and deletions must persist across sessions.
- **Navigation**: Back arrows must follow a predefined flow (Dispenser Details → Fuel Dispenser → Cash In → Home), overriding browser history.
- **UI**: Clean, responsive design, with empty state messages and compact layouts, utilizing small card containers for subsections.
</product_requirements>
